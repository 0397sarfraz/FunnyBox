# FunnyBox 😂

A fun React app to explore jokes, save your favorites, and keep them in your own "FunnyBox".  
Built with **React + Context API + TailwindCSS**.

---

## 🚀 Features
- Fetch jokes from API
- Display jokes (single line or setup/delivery type)
- Save jokes to favorites with ❤️ toggle
- Favorites page to view/remove saved jokes
- Responsive UI with TailwindCSS

---

## 🛠️ Tech Stack
- React
- Context API
- TailwindCSS
- React Icons
